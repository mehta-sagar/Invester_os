## Goal
Build `specs/collect_backfill.md`: an endpoint table (`config/backfill_endpoints.csv`, eight NSE `www` endpoints, all `to_probe`), a PROBE command that measures each endpoint (shape, row cap, earliest date, time of day, inclusivity, determinism) and refuses the backfill for any endpoint whose probe is not confirmed, a window planner with adaptive splitting (a window at the cap is split, never trusted), an append-only window ledger for stop-anywhere resume, raw byte-exact storage through the manifest (`backfill_<endpoint>`, `real_browser`), a nightly runner (2.5 s per request, one Chrome, a night window and budget, stop everything on a block, no stealth), `investos backfill status`, `investos check backfill`, and a launchd plist example. Parsing is NOT in scope.
