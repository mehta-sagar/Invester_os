# Brief S1-T2: Manifest schema v2 (access_mode, request_headers, schema)
- Stage: 1        - Branch: task/S1-T2        - Algorithm section: §4 "What every collector does" (manifest), decisions 0002 point 4 and 0002a
- Agents: Spec writer (Sonnet) → Test writer (Sonnet) → Builder (Sonnet) → Reviewer (Sonnet, fresh)

## Goal
Make the manifest version-aware and write v2 lines: every new row records `access_mode`, the exact `request_headers` sent, `final_url`, `fetch_host` (Cookie values redacted, null only for `real_browser` when the browser cannot report them) and a `schema` field. The reader accepts v1 (no `schema`, 8 fields) and v2 (11 fields) lines in any order and rejects everything else; the writer writes v2 only; `verify` flags malformed v2 lines and leaked cookies. This task merges first in stage 1: no v2 line may exist before every checkout can read it. Spec: `specs/core_manifest.md`, section "Stage 1 amendment" (R15 to R21, A24 to A34).
