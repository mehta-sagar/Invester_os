# Brief S0-T3: Manifest writer
- Stage 0 · Branch: task/S0-T3 · Algorithm §4 "What every collector does"
## Goal
`investos.core.manifest`: store raw bytes content-addressed at data/raw/<source>/<sha256[:2]>/<sha256> (write to temp, fsync, atomic rename, chmod 0444); append one JSON line per stored file to data/manifests/<source>.jsonl: sha256, size, url, fetched_at (UTC), source, source_version, logical_key (e.g. date), run_id. Lookup by (source, logical_key) and by sha256. Never overwrite or delete a raw file; same bytes → no new file, manifest line still records the fetch.
## Done means
- [ ] stored file is read-only and its hash re-verifies
- [ ] planted failures caught: tampered raw file (verify() reports mismatch), truncated manifest line, attempt to write over an existing hash with different bytes
- [ ] concurrent append safety (file lock) tested
