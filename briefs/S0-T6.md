# Brief S0-T6: Trial registry and decision log
- Stage 0 · Branch: task/S0-T6 · Algorithm §6 (every trial counted), §11 (decision log, daily root)
## Goal
`investos.registry.chain`: append-only JSONL ledgers with hash chain: each row = {seq, ts, prev_hash, payload, hash=sha256(canonical_json(seq,ts,prev_hash,payload))}. Genesis prev_hash = 64 zeros. `verify()` walks the chain and reports first broken seq. Daily root: Merkle-free simple root = hash of the last row of each IST day, written to <ledger>.roots.jsonl (to be committed to git).
Two ledgers on this base: `trials` (registry/trials.jsonl: trial_id, family, feature_id, params, hypothesis, registered_before_run=true) and `decisions` (data/ledger/decisions.jsonl: date, security_id, action buy/sell/hold/no_trade, reasons, model versions). No update/delete API exists.
