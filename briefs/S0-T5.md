# Brief S0-T5: Check runner and planted-failure harness
- Stage 0 · Branch: task/S0-T5 · Roadmap §3 (tests count only after seen failing)
## Goal
CLI `investos check [all|manifest|raw|registry|migrations]`: runs registered checks, prints a table, exits non-zero on any failure, writes a JSON report to reports/checks/<run_id>.json. Checks are plain functions registered with `@check(name)`.
Planted-failure harness: `investos check --planted`: for each check, apply its registered `plant()` fixture in a temp copy and assert the check FAILS; any check whose plant is not caught fails the harness. Every check must register a plant.
## Done means
- [ ] check without a plant → harness refuses to run it
- [ ] planted failures for manifest (hash mismatch), raw (writable file), migrations (edited file), registry (broken chain) all caught
