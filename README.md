# Invest OS

Private Indian equity research system. Skeleton created 2026-11-16. No code yet.

Design: see the architecture document (link kept in docs/ARCHITECTURE.md).

## What lives where
| Thing | Place | In GitHub? |
|---|---|---|
| Code, tests, migrations | src/, tests/, db/ | yes |
| Taxonomy and registries (sources, features, line items) | taxonomy/, registry/ | yes |
| Manifests: one line per raw file (url, sha256, fetched_at) | data/manifests/ | yes |
| Decisions, gate evidence, phase reports, verdicts | docs/ | yes |
| Raw bytes as downloaded | data/raw/<source>/<dataset>/<yyyy>/<yyyy-mm-dd>[__disc].<ext> | no |
| Parsed Parquet, per source and era | data/staged/ | no |
| Canonical DuckDB + Parquet (the truth store) | data/canonical/ | no |
| Features, models, backtests | data/features/, data/models/ | no |

## Rules carried over from ICID
1. acquire/ only fetches and manifests. parse/ never touches the network.
2. Raw is immutable, content-addressed, read-only.
3. Every number in a document is generated by code.
4. Every rule has a check, and every check is shown to go red before it is trusted.
5. Backtests read only through store.as_of(date).
